# 📊 Customer Shopping Behavior Data Analytics Project

## 📌 Overview

This project presents an end-to-end data analytics workflow to analyse customer shopping behaviour and generate actionable business insights. The goal is to help a retail business understand purchasing patterns, customer segments, and key revenue drivers to support data-driven decision-making.

---

## 🎯 Business Problem

A retail company aims to improve **customer engagement, sales performance, and long-term loyalty** by analysing customer behaviour across demographics, product categories, and purchasing patterns.

---

## 🧰 Tools & Technologies

* **Python (Pandas)** – Data cleaning, transformation, and exploratory data analysis
* **PostgreSQL** – Data storage and advanced querying
* **Power BI** – Interactive dashboard and data visualisation
* **Excel** – Initial data exploration
* **GitHub** – Project version control and portfolio showcase

---

## 📂 Dataset

* ~3,900 customers
* 18 features including:

  * Demographics (Age, Gender, Location)
  * Purchase details (Item, Category, Amount, Season)
  * Behavioural data (Discounts, Frequency, Reviews, Subscription status)

---

## 🔍 Project Workflow

### 1. Data Cleaning & Preparation (Python)

* Handled missing values using **category-based median imputation**
* Standardised column names (snake_case)
* Performed feature engineering:

  * Created **age groups**
  * Converted purchase frequency into numeric format
* Removed redundant columns

---

### 2. Data Analysis (SQL)

Performed advanced SQL analysis using:

* **Joins, aggregations, subqueries**
* **CTEs (Common Table Expressions)**
* **Window functions**

Key analyses:

* Revenue by gender
* Customer segmentation (New, Returning, Loyal)
* Top-performing products
* Discount impact on purchasing behaviour
* Subscription vs non-subscription revenue
* Revenue contribution by age group

---

### 3. Data Visualisation (Power BI)

Developed an **interactive dashboard** to track:

* Total customers
* Average purchase amount
* Customer segmentation
* Revenue by category and age group
* Subscription distribution

Features:

* Dynamic filters (slicers)
* KPI cards
* Drill-down insights

---

### 4. Reporting & Presentation

* Created a **structured project report** documenting methodology and findings
* Developed a **client-ready presentation** to communicate insights and business recommendations

---

## 📈 Key Insights

* Certain customer segments contribute significantly more to revenue
* High-rated products can be leveraged for marketing campaigns
* Discounts influence purchasing behaviour but require strategic balance
* Subscription programs show potential for increasing long-term revenue
